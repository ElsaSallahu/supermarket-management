# Supermarket Management System

## Project Description

Supermarket Management System është një aplikacion web i zhvilluar për menaxhimin e proceseve të një supermarketi. Sistemi mundëson menaxhimin e produkteve, kategorive, furnitorëve, klientëve, shitjeve, pagesave, faturave dhe përdoruesve përmes një ndërfaqe moderne dhe të lehtë për përdorim.

---

## Technologies Used

### Frontend

* React.js
* React Router
* CoreUI
* JavaScript
* CSS

### Backend

* Node.js
* Express.js

### Database

* MySQL

### Security

* Role Based Access Control (Admin, Manager, Cashier, Customer)

---

## User Roles

### Admin

* Menaxhon përdoruesit
* Menaxhon rolet
* Menaxhon punonjësit
* Ka qasje në raportet e sistemit
* Ka qasje të plotë në sistem

### Manager

* Menaxhon produktet
* Menaxhon furnitorët
* Menaxhon stokun
* Ka qasje në raporte

### Cashier

* Menaxhon shitjet
* Menaxhon pagesat
* Menaxhon faturat
* Menaxhon klientët

### Customer

* Shikon produktet
* Përdor pjesën e klientit të sistemit

## Installation

### Backend

```bash
cd backend
npm install
npm start
```

Backend runs on:

```txt
http://localhost:5000
```

### Frontend

```bash
cd frontend
npm install
npm start
```

Frontend runs on:

```txt
http://localhost:3000
```
